一句話結論

這一季獲利明顯高於我們的預測，主因是營益率。 三點論點都沒有被破壞，所以維持減碼。 等 10-Q 出來後，再做完整更新。

和我們預測的差異

差最多的是營業利益。

  • 營業利益實際 45.91B，我們預測 41.43B，高 10.8%。
  • 營收只比我們的預測高 1.3%。
  • 所以差異幾乎都來自成本端，不是來自營收。
  • 營益率 49.8%，我們預測 45.5%，高 4.3 pp。

原因：折舊拖累比我們算的輕。

  • 折舊、攤提等項目從 8,147M 增至 11,744M。¹
  • 銷售與行銷費用 5,716M，去年同季 5,717M。¹
  • 折舊確實在升，但營益率仍守在高檔。
  • 我們把折舊拖累算得太早，也算得太重。

一次性項目：OpenAI 投資損益。

  • OpenAI 投資淨利益讓本季淨利增加 207M，EPS 增加 0.03 美元。¹
  • 這筆列在營業外，不影響營業利益。
  • 剔除後，非 GAAP EPS 是 4.89 美元。¹
  • 剔除後，EPS 仍明顯高於我們的預測，方向不變。
  • 去年同季的 OpenAI 淨損失讓淨利減少 3.1B。¹
  • GAAP 淨利年增 32%，非 GAAP 淨利年增 18%。¹
  • 本業成長要看 18%；32% 多出來的部分是基期效應。

會延續嗎？營收面會，營益率只會部分延續。

  • Azure 營收年增 48%。¹
  • 商業 RPO 年增 73%，達到 677B。¹
  • 需求沒有鬆動，營收高於預測會延續。
  • 本季資本支出 39,367M，去年同季是 19,394M。¹
  • 資本支出還在加速，折舊會一季一季往上墊。
  • 營益率高出預測的幅度，接下來幾季會收窄。

論點檢查

1. 報酬低於門檻：削弱。

  • 單季盈餘高於預測，全年盈餘的基數跟著上移。
  • 只靠這一季，還不足以把總報酬推過門檻。
  • 評等要跨級，營益率高出預測的幅度必須延續整年。

2. 股價沒有高估：成立。

  • 高出預測的部分來自營業利益，不是 OpenAI 利益。
  • 經常性盈餘變高，31x P/E 的立足點更穩。

3. 資本支出砍不掉：成立。

  • 營運租賃使用權資產從 24,177M 增至 30,178M。¹
  • 已承諾的建置與租賃還在擴大。
  • 一旦需求轉弱，砍不掉的部分會比上次更大。
  • 不過觸發條件是 Azure 連兩季低於 30%，本季離這條線很遠。

下一步

  • 維持減碼，不提前重開研究小組。
  • 沒有論點被破壞。
  • 單季高出預測，也不足以讓評等跨級。
  • 轉偏空的條件沒有觸發：營益率與 Azure 成長都遠高於門檻。
  • 轉偏多的條件這季走反方向。
  • 營運現金流從 45,057M 增至 58,000M。¹
  • 資本支出的增幅大於營運現金流的增幅，FCF 年增轉正的條件沒有出現。
  • 兩條本季主張已經成立：Azure 維持高檔，營益率守住 47%。

10-Q 出來後，完整更新做四件事：

  1. 拆開營收成本，確認折舊進度，重估全年營益率路徑。
  2. 確認重編後的 Azure 口徑，和舊口徑是否可比。
  3. 用新的全年 EPS 重算目標價，檢查總報酬是否越過 10.2% 門檻。
  4. 調低熊情境的權重，因為 Azure 跌破 30% 的機率已經下降。
